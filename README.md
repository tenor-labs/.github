# .github

Tenor's GitHub organization profile.

- `profile/README.md` and `profile/tenor-header.png` are shown on [github.com/tenor-labs](https://github.com/tenor-labs).
- `assets/avatar.png` is the organization avatar. Upload it in the organization settings.
- `assets/social-<repo>.png` are the social previews of the public repositories. Upload each one in its repository's settings, under "Social preview".
